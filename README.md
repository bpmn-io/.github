# Default Organizational Resources

This repository contains the default organizational resources for the [bpmn-io GitHub organization](https://github.com/bpmn-io).

### Agent Instructions

[`.github/instructions/BPMN_IO.instructions.md`](./.github/instructions/BPMN_IO.instructions.md) holds the central instructions for coding agents. Repositories carry a copy of it, so GitHub Copilot picks it up, and point their `AGENTS.md` to it. Propagate changes to these copies.
